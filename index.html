ICARUS Profile Editor

Client-Side Profile Modifier

Load Profile Save

Drop your Profile.json here, or

Can't find it? On Windows your save lives at:
%LocalAppData%\Icarus\Saved\PlayerData\<YourSteamID>\Profile.json.

Press Win + R, paste %LocalAppData%\Icarus\Saved\PlayerData, then open the folder named with your Steam ID 64.

Edit Profile

Meta-Resources

Set in-game currency and resource counts directly. Values missing from your file are injected the moment you edit them.

Account Unlocks

Toggle individual unlock flags in the profile's UnlockedFlags list. Turning a flag on adds its value; turning it off removes it. Flags not in the catalogue below are left untouched.

Changes stay on this machine. Only the values you edit — MetaResources counts and UnlockedFlags entries — are modified; talents, stats, slots, and everything else are preserved exactly as loaded.

To apply it, overwrite your original Profile.json with the downloaded file while ICARUS is running and on the title screen. The game doesn't lock the file, so you don't need to close or restart it.

A quick word of caution: to preserve the intended experience, consider saving this tool for bug recovery or post-game convenience. If you've already conquered the content and just want to bypass tedious grinding, it's a great time-saver — otherwise, it can easily take the fun out of early progression.
